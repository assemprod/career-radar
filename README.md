# Career Radar — личный поисковик вакансий

**MVP на Next.js 14 / TypeScript / Tailwind CSS.** Под профиль IT Project Coordinator → Junior Product Manager / Business Analyst.

## Возможности
- Поиск **настоящих** вакансий через официальный HeadHunter API (host hh.kz, area Казахстана).
- Фильтры по специализации и региону, поисковому слову, зарплате и показу сохранённых.
- **Персональный порог для переезда: 600 000 ₸ net/месяц**, по умолчанию включён, редактируется в интерфейсе и сохраняется в `localStorage`.
- Три режима просмотра: **«Подходят»**, **«Уточнить условия»** (неопубликованная зарплата / пересечение порога / неизвестный gross-net) и **«Все»** (включая ниже порога).
- Прозрачная эвристическая оценка релевантности по должности, Jira, требованиям, внедрению и QA.
- Подсказки о пробелах: Scrum/Backlog, seniority, банковская сфера.
- Избранное в `localStorage` браузера (без регистрации).
- Официальные ссылки на QSamruk и Enbek. **В этой версии их вакансии не загружаются автоматически**.
- Никаких выдуманных вакансий, результатов, зарплат или имитации API.

## Запуск
```bash
npm install
cp .env.example .env.local
npm run dev
```
Открыть http://localhost:3000.

## Доступ к hh.kz API
Зарегистрируйте приложение на https://dev.hh.kz/ и получите необходимые разрешения. Для некоторых запросов требуется OAuth: без токена HH может показать капчу после первого запроса. Укажите действующий токен в `.env.local`:
```dotenv
HH_OAUTH_TOKEN=...
HH_API_CONTACT=your.email@example.com
```
**Никогда не публикуйте токен в клиентском коде или GitHub.** Backend автоматически покажет понятное сообщение, если hh.kz заблокировал запрос, вместо фальшивых вакансий.

## Источники
1. HH API — **действующий backend-адаптер**. Docs: https://api.hh.ru/openapi/redoc
2. QSamruk — **только ссылка на официальный каталог**: https://qsamruk.kz/vacancy . Публичный API не был подтвержден.
3. Enbek — **только ссылка на официальный каталог**: https://enbek.kz/ru . Их страница перечисляет XML-фиды: https://enbek.kz/ru/web-services , однако прямые ссылки на фиды в момент проверки ответили ошибкой; прежде чем включать автоматический импорт, нужно подтвердить доступность и условия.

## Доход и переезд
- Порог **600 000 ₸ на руки в месяц** применяется к вакансиям в других городах, если нет явно подтверждённого полностью удалённого формата. Базовый город профиля: Кульсары. Гибрид в другом городе считается предполагающим переезд; точный формат нужно уточнить на собеседовании.
- При `gross: false` зарплата сравнивается с порогом как объявленная работодателем сумма на руки. При `gross: true` система использует **примерную** конверсию для обычного наёмного сотрудника-резидента Казахстана в **2026 году**: ОПВ 10%, ВОСМС 2%, стандартный вычет 30 МРП, ИПН 10%, выше годового порога 8500 МРП — 15%. Для высоких окладов годовой порог аппроксимирован помесячно. Обозначение `≈` предупреждает о приблизительном расчёте.
- Ориентир: 600 000 ₸ **gross** — примерно 488 175 ₸ **net**, 800 000 ₸ gross — примерно 646 575 ₸ net, при указанных допущениях. Это не индивидуальный налоговый расчёт.
- Если зарплата вообще не указана, валюта не KZT или неизвестно, gross это или net, вакансия попадает в «Уточнить условия», **а не исключается безвозвратно**.
- Диапазон считается подходящим только когда **нижняя граница** уже проходит порог. Если нижняя граница не проходит, а верхняя может проходить, это «Уточнить условия». Если **верхняя граница** ниже порога — «Все» (не подходит по доходу).
- Для действительно удалённых вакансий и работы в Кульсары порог переезда **не применяется**. Отдельные зарплатные предпочтения для удалённой работы пока не заданы.
- Настройки сохраняются только в браузере, без аккаунта и синхронизации устройств.
- Справка о ставках: https://www.gov.kz/memleket/entities/kgd-vko/press/news/details/1238674?lang=ru и https://qazatlas.kz/ru/calculators/zarplata .

## Проверка логики фильтра
На Node.js 22+ можно запустить тесты независимо от загрузки HH:
```bash
npm run test:salary
```

## Релевантность
`lib/jobs.ts` присваивает рейтинг **0–99 баллов эвристики**, не вероятность получения оффера. Работа только с полями краткой выдачи HH; для более точного ранжирования добавьте API деталей вакансии и дополнительное подтверждение прав на вызовы.

## Хранение данных и безопасность
Пользовательское резюме не загружается на внешние серверы. Предустановленный профиль зафиксирован в коде `lib/profile.ts`; персональные контакты в публичных страницах не показываются. Избранное хранится локально в браузере. Публичную публикацию приложения рекомендуется закрыть логином, если добавите CV и историю откликов.
